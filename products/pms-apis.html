How It Works

What PMS APIs are, and how they work.

PMS APIs are documented, secure REST endpoints that let revenue management tools, analytics platforms and technology partners pull rates and inventory or push bookings directly into eGlobe PMS, instead of relying on manual exports.

1

Get API credentials

We issue OAuth 2.0 secured access for your integration.

2

Build against the docs

Well-documented endpoints and a sandbox make integration straightforward.

3

Pull or push data in real time

Rates, inventory and bookings sync bi-directionally as they change.

4

We support the integration

A dedicated team is available while you build and after you go live.
